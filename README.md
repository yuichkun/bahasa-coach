# Bahasa Coach

Mac でインドネシア語の会話と作文を練習する、自分用のローカルアプリです。字幕・作文・添削を SQLite に保存し、直近10回の練習を次のお題に反映します。

## 起動

Node.js 24 以上、Vite+ (`vp`)、Codex CLI が必要です。

```sh
cd /Users/yuichkun/workspace/bahasa-coach
vp install
vp dev
```

[http://localhost:43187](http://localhost:43187) を Chrome で開きます。UI と API が一緒に起動します。終了はターミナルで Ctrl+C。43187 と内部 API 用の43188を使用するため、同時に複数起動しないでください。

「接続設定」で ChatGPT にサインインしてください。認証は公式 Codex App Server が管理し、文章の出題・添削はサブスクリプションの利用枠を使います。アプリ専用の認証領域を使用するので、普段の Codex とは別に初回サインインが必要です。利用枠そのものは共有します。文章 API への自動切替はありません。

音声には GPT-Live-1 を使用できる OpenAI プロジェクトの API キーが必要です。接続設定で保存するか、`.env.example` を参考に `.env` に `OPENAI_API_KEY` を設定します。キーはサーバーだけで扱い、Codex の子プロセスには渡しません。音声は別料金です。

## 使い方

- **会話**：「話す」で Rani との自由会話を開始できます。Rani はバンドンで働く架空の会話相手で、料理・写真・仕事や恋人との日常の話を持っています。自分の近況や感想も交え、毎回質問で締める面接形式を避けます。過去の会話の抜粋を参照し、新しいレッスンでは別の話題から始めます。マイクをオフ→オンにしても同じ設定・話題を引き継ぎます。お題は不要です。「テーマを決めて練習する」は任意の入口です。
- **字幕**：受信した断片は原文のまま保存し、表示するときに継続中の文をつなぎます。単語へのホバー・クリック・キーボードフォーカスで、その文脈の意味と正式形を調べられます。字幕・表示中の文章から単語をまとめて先読みします。取得済みの意味は SQLite とブラウザに保存し、再読み込み後も再利用します。基本の意味がある単語はすぐ表示し、文脈に応じた意味は裏で確認します。未取得で先読みも終わっていない語だけは待ち時間が残ります。Escape で閉じられます。
- **文全体の訳**：会話の単語ポップアップの下に、その文全体の日本語訳も表示します。前後の発言と、同じ発言内の前後の文を翻訳に渡します。表示中の字幕と返答ヒントから先読みし、同じ文脈の結果は SQLite とブラウザに保存します。別の文脈では訳し直し、単語を替えてホバーしただけなら同じ訳を再利用します。初めての文で先読みが終わっていない場合は待ち時間が残ります。
- **マイク**：中央のアイコンか `M` キーでオン／オフを切り替えます。オフにすると音声接続を閉じ、その間の音声課金を止めます。同じボタンをオンにすると、字幕とヒントを残して同じレッスンへ再接続します。入力欄・日本語変換中・ダイアログ内・接続の切り替え中にはショートカットが反応しません。
- **返答のヒント**：相手の直前の発言に合わせ、短いインドネシア語の例と日本語の意図を最大３つ表示します。入力・送信は自動で行いません。自分が読み上げている間や字幕が更新されている間もヒントを保持し、相手が次の発言をしたときに更新します。
- **会話中の添削**：自分の発言を裏で確認し、役立つ修正があるときだけ、その発言の下に自然な口語と日本語の理由を表示します。会話を止めたり、添削を読み上げたりしません。原文は上書きせず、添削は履歴と次の出題に残ります。未完文・不確かな聞き取り・混在言語を無理に誤りとせず、同じ字幕への確認結果は再利用します。字幕が伸びた場合は古い添削を外して確認し直します。失敗時は一度自動再試行し、続けて失敗した場合だけ再試行ボタンを表示します。
- **レッスンノート**：会話終了後は毎回、専用ページへ進みます。会話全体を話題ごとに振り返り、実際の表現・自然な言い方・使い分けの理由・応用例を表示します。重要な語句をハイライトし、単語の意味と正式形も確認できます。項目数や文章量を固定せず、重複を整理します。保存済みのノートは履歴から開けます。
- **作文**：お題に回答して「回答を確認する」。添削は意味のある１点に絞ります。

## 学習の流れ

会話中の添削は自動で表示・保存します。会話後はレッスン全体のノートを自動で作成します。言い直して練習する際は、ノート内の「この表現を、書いて使ってみる」から進みます。

1. 実際の自分の発言・作文に引用元を持つ修正を１つ提示します。根拠がない指摘や、訂正前後が実質同じ提案は練習対象にしません。
2. 「もう一度話す／書く」で見本を閉じ、同じ意図を自分の表現で出力します。
3. 新しい回答に根拠を持つ確認結果を保存します。見本・単語の説明・返答ヒントなどを使った練習は支援ありとして区別します。音声の再練習は「回答を確認して終了」で確認します。
4. 自力の言い直しを確認したら、次のお題で別の状況に移します。「別の場面で使う」からも進めます。１回の成功を習得済みとは扱いません。

確認できない回答は進捗を進めません。元の字幕を訂正した場合は、以前の評価を無効にして確認し直します。過去の履歴・生の字幕・補正履歴は保持します。

## 保存と料金

データはリポジトリ内の `.local/bahasa.sqlite` に保存します。`.local/` と `.env` は Git 管理および開発サーバーのファイル配信・監視から除外します。アプリが保存するのはテキストとフィードバックだけで、音声録音は保存しません。OpenAI 側の Live 録音保存も `store: false` です（サービス自体のデータ取り扱いポリシーとは別です）。

音声の単価は $0.05／分で概算します。WebRTC 接続の初期化には15秒分の料金が発生し、その後の音声時間に充当されます。最終の利用時間イベントを優先し、確認できない場合は未確定として残します。金額による自動停止はありません。マイクをオフにして音声接続が終了すると、それ以降の接続時間は課金されません。オンに戻すと再接続するため、初期化料金が再び発生します。接続ごとに料金を保存し、同じレッスンを再開しても二重計上しません。

API キーは `.local/voice-key`、Codex の認証は `.local/codex/` に保存されます。このフォルダを他人と共有しないでください。データのバックアップはアプリを終了してから `.local/` をコピーすると、SQLite の関連ファイルもまとめて保存できます。

## 検証とビルド

```sh
vp check
vp test
vp build
```

テストは一時データベースとテスト用の AI／音声接続を使い、実アカウントや有料 API を呼びません。実際の音声品質、割り込みの体感、混在言語の認識は、接続設定後の実通話で別途確認します。

ビルド済み UI を使う場合は `vp run start`。通常は `vp dev` だけで利用できます。

## MVP の範囲

PWA、常駐サービス、Dropbox、デプロイ、録音再生、厳密な習熟スコアや間隔反復は含みません。

## 単語表示のキャッシュ

- 文単位のキーを使い、後続の字幕や空白・大文字小文字の違いだけでキャッシュを捨てません。
- 常用語の基本義と、先読みで取得した辞書の基本義は、別の文でも即時表示できます。基本義には「基本の意味」と表示します。
- 文脈で選ばれた多義語の意味は、別の文脈へそのまま流用しません。同じ文に同じ語が複数出る場合も区別します。
- 先読みはまとめて実行し、ホバー中の語が先読み中なら同じ処理を共有します。先読みそのものは「ヒントを見た」学習記録には入りません。

会話中の添削は最後の字幕更新から約2.2秒後に確認を始めます。これは発話終了の確定ではありません。字幕の続きが来た場合は、その途中の文に対する結果を採用しません。モデルの応答時間が別途かかり、会話・返答ヒント・辞書とは独立して処理します。

レッスンノートは `#/recap/<lesson-id>` で開けます。生成中に画面を離れても処理を続け、失敗時は再試行できます。出典のない引用や、前半の話題を落とした結果は採用しません。休止中は生成せず、実際にレッスンを終了してから生成します。
